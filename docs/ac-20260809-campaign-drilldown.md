# 广告活动第3层下钻验收标准

## 范围与数据流

- 第1层：词元排行。
- 第2层：双击词元，按该词元及英文单复数变体汇总完整搜索词。
- 第3层：双击第2层的完整搜索词，按广告活动名称汇总源记录。
- 第3层只统计搜索词完全相同且广告活动名称非空的源记录，继续叠加页面业务筛选、数值筛选和排序规则。
- 第3层第一列字段显示为广告活动名称，其余10个指标及计算公式不变。
- 第3层支持表头筛选、组合排序、上一页、下一页、当前页导出、全部导出和撤销恢复。

## 边界处理

- 完整搜索词没有广告活动名称时，表格显示0行，分页显示第1/1页，状态文字说明没有关联广告活动名称。
- 从第2层进入第3层时，清除仅适用于完整搜索词第一列的文字筛选；其余指标筛选保留。
- 第3层双击行不再继续下钻，避免产生不存在的第4层。
- 清空搜索返回词元排行；撤销返回进入第3层前的完整搜索词页面。
- 数据库读取失败时保留当前表格，并显示无法下钻提示。

## 验收标准

### AC-1：进入广告活动下钻

- 前置：第2层存在一个完整搜索词，且该搜索词关联至少2个非空广告活动名称。
- 操作：双击该完整搜索词。
- 期望：标题变为广告活动溯源；第一列表头变为广告活动名称；每行代表一个广告活动名称；其余指标为该活动下对应源记录的汇总值。

### AC-2：排序、筛选与分页

- 前置：第3层存在多条广告活动记录。
- 操作：设置2个组合排序字段，再设置任意表头筛选并切换页面。
- 期望：结果按组合规则执行，筛选三角显示生效状态，分页总数来自筛选后的广告活动数量。

### AC-3：导出

- 前置：第3层存在结果。
- 操作：分别导出当前页和全部结果。
- 期望：XLSX第一列标题为广告活动名称，其余字段顺序与页面一致；全部导出应用当前业务筛选、表头筛选和排序规则。

### AC-4：空结果与撤销

- 前置：第2层完整搜索词没有非空广告活动名称。
- 操作：双击该行，再执行撤销。
- 期望：第3层显示0行且状态说明没有关联广告活动名称；撤销后恢复原第2层页面、页码、筛选和列宽。
