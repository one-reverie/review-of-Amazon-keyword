# 企业内部固定激活码验收标准

## 范围

- 每台电脑首次启动时要求输入企业内部激活码
- 当前内部激活码按用户指定值固化为摘要，不按设备分别生成，明文不进入仓库
- 激活成功后本机自动进入，后续启动不重复输入
- 激活过程完全离线，不调用服务器，不产生费用
- 不包含管理员生成器、设备绑定、远程撤销、设备数量统计和到期续费

## 安全边界

- 客户端源码只保存固定码的SHA-256校验摘要，不保存明文固定码
- 本地激活标记使用Windows当前用户DPAPI加密保存
- 固定码可在企业内部共享，拿到固定码和安装包的人均可激活，不能实现按设备控制

## 验收标准

### AC-1：首次启动门禁

- 无有效激活标记时，只显示激活码输入框、激活按钮和退出按钮
- 关闭激活窗口时退出程序，不创建主窗口

### AC-2：固定码验证

- 输入线下分发的正确企业固定码时激活成功
- 输入错误值或空值时不写入激活文件，继续停留在激活窗口

### AC-3：自动进入

- 首次激活成功后创建主窗口
- 再次启动时直接创建主窗口，不重复要求输入

### AC-4：加密保存

- `%LOCALAPPDATA%\TokenAnalyzer\activation.json`中不得出现明文固定码
- 激活标记使用Windows当前用户DPAPI保护

### AC-5：异常恢复

- 激活文件损坏、旧版格式或DPAPI解密失败时按未激活处理，不崩溃
