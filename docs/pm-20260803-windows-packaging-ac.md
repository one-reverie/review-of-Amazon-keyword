# Windows安装包验收标准

日期：2026-08-03

## 范围与假设

- 交付对象是不安装Python、不会使用命令行的Windows10或Windows11普通用户。
- 用户所说的安装列表按安装目录理解，安装向导必须显示目录选择页。
- V1使用Nuitka生成独立应用目录，再由Inno Setup生成一个安装程序EXE。
- 安装采用当前用户权限，不要求管理员授权。
- 本轮不加入登录、授权码、自动更新、代码签名和联网下载依赖。

## B1实体与生命周期

### 应用安装

生命周期：未安装→选择安装目录与快捷方式→安装中→已安装→卸载

牵连关系：

- 安装成功后创建开始菜单入口，可选创建桌面快捷方式。
- 卸载只删除程序文件和快捷方式，不删除用户导入的数据、模型设置或加密API密钥。

### 用户数据

生命周期：首次启动无数据→用户导入Excel→保存本地数据库→后续启动继续读取

牵连关系：

- 数据库和设置保存在当前用户的LocalAppData，不写入安装目录。
- 重新安装或升级程序不得覆盖用户数据库和设置。

### 构建产物

生命周期：源码→Nuitka独立目录→Inno安装程序→交付

牵连关系：

- 构建目录、用户数据库、Excel和密钥配置不得加入Git。
- 安装程序不包含开发时的`data/current.duckdb`。

## B2五个必问

- 空状态：首次启动显示现有导入Excel引导，统计、筛选和AI按钮保持无数据状态。
- 失败：缺少Nuitka时构建脚本停止并提示安装命令；缺少Inno Setup时停止并提示免费安装来源；构建失败不得覆盖上一次成功的安装包。
- 被引用：卸载保留LocalAppData中的用户数据，避免同事误删业务数据。
- 并发：构建脚本按固定输出目录工作，同一项目不支持两个构建同时运行。
- 后悔：安装程序提供卸载入口；桌面快捷方式是可选项；用户可返回修改安装目录。

## B3输入输出

输入：

- `main.py`和`src/token_analyzer/`源码。
- PySide6、DuckDB、Pandas、python-calamine及其运行依赖。
- 应用图标、Inno Setup脚本和版本信息。

输出：

- `dist/TokenAnalyzer/`：可直接运行的独立应用目录。
- `dist/installer/词元分析器-安装程序-<版本>.exe`：唯一需要发给同事的文件。

## B4优先级

### 必须在V1实现

1. 无Python环境可启动应用。
2. 安装向导显示安装目录页。
3. 可选桌面快捷方式、开始菜单入口和卸载入口。
4. 用户数据和模型设置写入LocalAppData并在卸载后保留。
5. 安装包不包含测试数据库、Excel、API密钥和源码测试文件。
6. 中文Windows安装与启动验证通过。

### 应该在V1实现

1. 应用和安装程序使用统一图标。
2. 安装完成页可选择立即启动应用。
3. Git忽略虚拟环境、用户数据和全部构建产物。

### 可以延后

1. 代码签名。
2. 自动更新。
3. 企业集中部署和静默安装文档。

## B5验收标准

### AC-1：Git初始化与安全忽略

- 前置：项目尚未初始化Git。
- 操作：执行Git初始化并查看状态。
- 期望：分支为`main`；`.venv`、`data/current.duckdb`、构建目录、安装包和用户设置不出现在待提交文件中。

### AC-2：独立应用构建

- 前置：本机安装免费Nuitka及编译依赖。
- 操作：运行Windows构建脚本。
- 期望：生成`dist/TokenAnalyzer/TokenAnalyzer.exe`；关闭Python开发环境后仍可启动；首页首次启动进入无数据导入页。

### AC-3：安装向导

- 前置：已生成独立应用目录并安装Inno Setup6。
- 操作：运行生成的安装程序。
- 期望：显示中文许可外的欢迎、安装目录、附加任务、准备安装、完成页面；安装目录可修改；桌面快捷方式可勾选。

### AC-4：安装后入口

- 前置：完成安装。
- 操作：分别从桌面快捷方式和开始菜单启动应用，再打开Windows应用卸载入口。
- 期望：两个快捷方式均启动同一应用；系统中存在词元分析器卸载项。

### AC-5：用户数据持久化

- 前置：安装应用并导入Excel，保存一个模型配置。
- 操作：关闭后重开应用，再卸载并重新安装。
- 期望：重开和重装后仍能读取同一用户数据库和设置；安装目录中不存在`current.duckdb`和明文API密钥。

### AC-6：安装包内容安全

- 前置：完成构建。
- 操作：检查独立应用目录和安装脚本文件清单。
- 期望：不包含`.venv`、`tests`、`docs`、原始Excel、开发数据库、截图、Git目录或设置文件。

### AC-7：最终交付

- 前置：安装、启动、卸载测试通过。
- 操作：查看`dist/installer/`。
- 期望：存在单个带版本号的安装程序EXE；交付说明明确指出只需把该文件发给同事。
