# 词元分析增强验收标准

## 范围

本轮只增强当前批次的导入、分析、导出和界面状态。撤销、重做仅针对页面查询状态，不恢复已被新文件替换的数据批次。

## 验收标准

### AC-1：多格式导入与原子替换

- 支持`.xlsx`、`.xlsm`、`.csv`、`.txt`，只读取Excel的第一个工作表
- `.csv`和`.txt`接受UTF-8、UTF-8 BOM、GBK编码，自动识别逗号、制表符或分号分隔
- 必需字段仍为搜索词、展示量、点击量、购买量；缺列或不能读取时展示明确原因，旧本地数据保持不变
- 成功导入后继续使用暂存DuckDB文件替换正式文件，不保留源Excel或API密钥到安装目录

### AC-2：成本与销售指标

- 导入总成本、销售额字段时，词元排行和完整搜索词均展示总成本、销售额、ACOS、CPC
- ACOS等于总成本除以销售额，CPC等于总成本除以点击量，分母为0时展示`—`
- 表头为总成本、销售额、ACOS、CPC并提供悬浮说明；源表未提供成本或销售额时仍显示四列，并提示其为缺失源数据或公式指标
- 四项指标可作为排序维度，和表头排序同步

### AC-3：表格排序、筛选与列宽

- 点击可排序表头时，主排序控件、表格排序箭头、当前列表三者同步；再次点击同一表头切换升序或降序
- 表头提供Excel风格下拉入口，用于显示排序命令与当前列说明；页面已有的日期、币种、广告组合、广告活动、广告组、搜索词类型筛选保持相互联动并继续统一作用于表格、搜索和AI推荐
- 11列均能像Excel一样自由拖动和双击自适应；第一列不再因其余列宽度被自动压缩，超出视口时由表格横向滚动条承载

### AC-4：固定搜索与词元下钻

- 搜索条始终固定在分析内容顶部，页面纵向滚动时不离开可视区
- 双击词元排行的词元后进入完整搜索词溯源，保留当前排序和页面筛选
- 溯源支持常见英文单复数及woman、women关系的模糊匹配，手动输入搜索仍默认精确匹配
- 溯源结果旁展示涉及广告活动的可选列表，选择某活动后继续与其余筛选取交集

### AC-5：导出

- 主表导出菜单提供导出当前页与导出全部结果，生成`.xlsx`并包含当前视图、排序和全部11列指标
- 无数据时导出入口禁用；导出失败不影响当前列表，展示原因
- AI推荐结果窗口提供导出Excel，单词词元、组合词元分别写入工作表，包含推荐分、指标、理由和风险提示

### AC-6：界面撤销与重做

- 顶部提供撤销、重做图标，最多保存5个页面状态
- 可撤销和重做搜索词、搜索溯源模式、排序字段和方向、6项筛选、已加载条数
- 导入替换、导出、AI联网请求和模型设置不进入撤销历史；执行这些动作前后不得破坏现有历史

### AC-7：信息层级

- 在完整搜索词溯源页移除低频的匹配搜索词Top10图，表格区域获得更多可视空间；词元排行页保留当前排序维度的Top10图
- 统计卡和状态栏补充总成本、销售额、ACOS、CPC说明，不因新增指标阻断原有曝光、点击、订单、CTR、CVR展示
