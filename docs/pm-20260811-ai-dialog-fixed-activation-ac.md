# AI推荐弹窗与企业固定激活码AC

## AC-1：AI推荐表格只读

- 单词词元和组合词元两个页签的所有单元格均不可编辑
- 双击、键盘输入和粘贴均不得修改数据
- 单元格文字仍可选中或通过复制操作取得

## AC-2：弹窗空间与列宽

- AI推荐弹窗默认最大化，可使用系统按钮还原和再次最大化
- 所有数据列先按内容计算可读初始宽度，再切换为可拖动模式
- 推荐理由和风险提示使用独立宽度，不再通过Stretch挤压到不可读
- 后续列超出窗口时显示水平滚动条

## AC-3：冻结词元列

- 视觉序号列和词元列在水平滚动时保持固定
- 分类、指标、推荐理由和风险提示随水平滚动
- 冻结区域与主表垂直滚动、行高和选中行同步，不出现重复文字

## AC-4：复制

- 词元列右键提供复制完整内容
- 当前单元格支持`Ctrl+C`
- 复制不改变只读状态，不触发编辑框

## AC-5：固定激活码

- 首次启动只显示激活码输入、激活并进入和退出，不显示设备码或管理员生成器说明
- 企业内部固定码按用户指定值固化为摘要且明文不进入仓库；错误或空值不写入激活文件
- 成功后使用Windows当前用户DPAPI保存激活标记，后续启动自动进入
- 源码不保存固定码明文，只保存校验摘要
- 移除设备专属生成器、管理员私钥和非对称签名依赖

## AC-6：回归

- 主分析页三层表格、AI推荐导出、AI模型调用范围和本地指标不得受影响
- 本轮只运行开发版和测试，不生成安装包
