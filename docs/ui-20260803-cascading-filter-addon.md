## 增量结论

1. 所有筛选组合框增加固定箭头区，不依赖操作系统默认箭头。箭头参考Excel筛选控件的清楚程度，但继续使用项目现有橙色选中、绿色数据和中性边框。
2. 6项筛选采用排除自身条件的分面级联。某一筛选的候选项由其余5项已选条件计算，因此列表里每个可选值都至少能返回1条记录。
3. 级联不会自动选择、清除或替换用户条件。选项收窄通过匹配数、列表底部说明和状态文字表达。
4. 当前值和长选项都提供全文tooltip；下拉弹层按内容扩宽，正文保持不透明，透明度只用于阴影和tooltip。

## frontend-design取舍

- 采用明确视觉反馈、受控密度和关键hover。箭头、选中态、计数和弹层层级都服务筛选判断。
- 不使用网页式玻璃、渐变、强阴影和装饰动画。下拉是桌面工具控件，清楚度优先。
- 不更换字体和橙绿配色。项目现状优先于frontend-design的字体与破格布局建议。

## 下拉箭头

### 尺寸

| 项目 | 规格 |
|---|---:|
| 组合框总高 | 40px |
| 箭头点击区 | 32×38px，位于右侧，距外边框1px |
| 箭头图形 | 12×8px，2px描边，圆角线帽 |
| 箭头与右边缘 | 10px |
| 当前值右侧安全区 | 40px，文字不得进入箭头区 |
| 箭头区分隔 | 左侧1px`border-subtle`，高度20px，垂直居中 |

- 箭头使用共享矢量图标，不使用字符`v`、`⌄`或依赖系统主题的原生图形。Windows缩放到125%、150%和200%时仍需清楚。
- 整个组合框都可点击，32px箭头区是视觉提示，不缩小点击范围。
- 箭头默认使用主文字色；hover使用`accent-primary`；展开后改为向上并保持橙色。
- 选中非全部值时继续使用既有浅橙背景和橙色左侧状态线，箭头不新增第二种橙色。
- 日期可在当前值左侧保留日历图标；其他字段不增加漏斗图标，避免把字段类型和已筛选状态混在一起。

### 状态

| 状态 | 箭头与控件反馈 |
|---|---|
| Default | 向下箭头清楚可见，箭头区无独立底色。 |
| Hover | 组合框边框提高一级对比，箭头区使用`accent-primary-soft`，箭头变橙，160ms ease-out。 |
| Focus | 保留2px橙色focus ring，箭头变橙；focus ring不能被弹层遮住。 |
| Open | 箭头向上，箭头区保持浅橙；弹层出现后控件仍显示当前值。 |
| Selected | 浅橙字段背景、左侧橙线、完整当前值tooltip；箭头规则不变。 |
| Updating | 箭头区临时显示14px进度环，控件保留原值并阻止重复选择。超过200ms才显示进度环。 |
| Disabled | 箭头和文字使用disabled色，仍保留字段label和禁用原因tooltip。 |

## 关联筛选模型

### 计算规则

6项筛选不采用固定的单向父子链。日期、币种、广告组合、广告活动、广告组和搜索词类型都使用同一分面规则：

```text
某字段的候选值＝完整数据应用其余5项已选条件后的非空去重值
```

示例：当前选择币种EUR和广告组合DE-KM166时，打开广告活动，只显示同时属于EUR和DE-KM166且至少有1条记录的活动。计算广告活动选项时暂时忽略广告活动自身当前值，所以用户仍能在兼容活动之间切换。

### 该规则如何避免空集

- 用户只能选择候选列表中匹配数大于0的值，因此由筛选组合本身造成的结果空集不会出现。
- 每次选择完成后，一次刷新其余5个字段的候选项、KPI、Top10和表格。所有区域使用同一结果快照。
- 当前已选组合在每一步都有效，不会出现选择新值后又静默清除旧值的情况。
- 辅助搜索不参与筛选候选项计算。筛选组合保证有数据，但筛选后再搜索仍可能没有搜索结果，此时沿用基线文档的搜索无结果状态。
- Excel对应列为空时，该字段显示`当前范围无可选项`并disabled，不影响其他字段和当前结果。

### 用户如何理解选项变化

- 候选项右侧显示匹配记录数，例如`DE-KM166（12,408）`。名称左对齐，计数使用辅助文字和等宽数字右对齐。
- 弹层顶部搜索框下方显示`当前可选18项`。字段未受其他筛选限制时只显示该句。
- 候选项被其他筛选收窄时，弹层底部固定显示`已根据其他筛选显示18/246项`，下一行显示`清除其他筛选可查看全部选项`。
- 组合框label不改变名称，不使用模糊的已联动标记。已选字段继续靠具体值和橙色状态线表达。
- 页面状态栏在更新完成后显示`筛选已更新：3项条件，48,690条记录`。
- 全局`重置筛选`仍是唯一批量清除入口。级联过程不自动选择唯一候选，也不自动清除任何已选值。

### 选择时序

1. 用户在一个弹层中选择候选项，弹层立即关闭，字段显示新值。
2. 160ms内合并连续操作；查询超过200ms时，其余筛选箭头区显示进度环。
3. 一次提交新的候选项、选项计数和页面数据。禁止筛选框先后闪烁或KPI与表格短暂使用不同条件。
4. 刷新后保持页面滚动位置、表格滚动位置和其他字段焦点；焦点返回刚操作的字段。
5. 查询失败时恢复选择前的全部候选项和页面结果，字段下方显示错误图标与简短说明，不留下半更新状态。

## 当前值与长选项全文

### 组合框当前值

- 当前值区域为控件左侧至箭头安全区前，左右内边距各10px，单行右侧省略。
- `全部`和`全部时间`不显示tooltip。非全部值hover300ms后显示全文，即使当前值尚未省略也可显示，保证行为稳定。
- 当前值tooltip内容为字段名加完整值，例如：

```text
广告组合
DE-XYL-JYMT19
```

- 日期全文保持Excel源值，不把省略后的`2026年7…年7月24日`继续带入tooltip。
- tooltip距控件8px，优先出现在控件下方；若下方是已打开弹层，则放在控件上方，不覆盖箭头和当前值。

### 下拉长选项

- 选项行高36px，左内边距10px，右侧为计数区与滚动条安全区，总计至少78px。
- 名称单行右侧省略。hover300ms后仅对被省略的选项显示全文tooltip，未省略项不重复弹出。
- 选项tooltip第一行显示完整名称，第二行显示`匹配记录12,408条`。日期只显示完整日期范围和匹配数。
- tooltip宽度按内容计算，最小220px，最大420px；超过最大宽度后在自然语义边界换行，禁止中英文单字孤行。
- tooltip内边距8px，6px圆角；正文使用项目tooltip文字层级。

## 下拉弹层

### 宽高与定位

| 项目 | 规格 |
|---|---:|
| 最小宽度 | 当前组合框宽度与280px取较大值 |
| 推荐宽度 | 最长可见选项文字宽＋勾选区24px＋计数区72px＋左右内边距20px＋滚动条12px |
| 最大宽度 | 440px |
| 最大高度 | 320px |
| 搜索区 | 44px，仅选项超过20项时出现 |
| 选项行 | 36px |
| 底部关联说明 | 48px，仅候选项被收窄时出现 |
| 控件与弹层间距 | 4px |

- 弹层优先向下展开，空间不足时向上展开；始终限制在当前屏幕可见区域内。
- 靠近右侧窗口边缘的广告组和搜索词类型弹层向左对齐，不允许被窗口裁掉。
- 日期弹层推荐宽360px，广告组合、广告活动和广告组根据最长可见值动态取宽，最多440px。币种和搜索词类型不为短选项强行扩到最大宽。
- 弹层覆盖下方KPI和图表，不推动页面重排，也不改变页面滚动位置。

### 阴影与透明度

- 弹层内容背景使用`surface-card`，不透明度100%。长文字列表禁止玻璃效果或半透明底，否则下方图表会干扰阅读。
- 弹层使用1px`border-subtle`和系统浮层阴影。阴影模糊半径18px，垂直偏移6px，阴影不透明度18%。
- tooltip背景沿用项目深色tooltip，整体不透明度96%；文字不透明度100%。
- 下拉出现和关闭只做160ms透明度变化，不缩放、不弹跳。减少动态效果时立即显示和关闭。

### 弹层状态

| 状态 | 规格 |
|---|---|
| Default | 不透明白色弹层、细边框、轻阴影，第一项为全部。 |
| Hover | 当前行使用`surface-hover`；长文本延迟显示tooltip。 |
| Focus | 键盘高亮行使用独立focus ring，不与橙色已选行混淆。 |
| Selected | 行首14px橙色勾选，行底使用`accent-primary-soft`，右侧保留匹配数。 |
| Searching | 顶部搜索框过滤当前关联候选，不修改页面筛选。 |
| Search empty | 显示`当前关联条件下没有该选项`和`清除搜索文字`，不清除页面筛选。 |
| Cascaded | 底部显示当前项数、全量项数和收窄原因说明。 |
| Loading | 保留原列表，顶部显示细进度条；不把列表清空成白框。 |
| Error | 保留原列表并显示错误图标和`关联选项更新失败`，关闭后恢复选择前状态。 |

## 键盘与可访问性

- Alt+下方向键或Space打开，Esc关闭，Enter选择，上下方向键移动，Home和End跳转。
- 箭头只作视觉提示，组合框可访问名称仍使用字段label；展开和收起状态通过可访问状态暴露。
- 选项可访问名称包含完整值和匹配数，不读取省略文本。
- 候选项收窄提示可被屏幕阅读器读取，但每次只播报一次汇总，例如`广告活动可选18项，受2项其他筛选限制`。
- 选中、不可用和错误状态都同时使用图标或文字，不能只用橙、灰、红表示。

## 验收状态

| 场景 | 必须结果 |
|---|---|
| 1280×820展开侧栏 | 6个筛选都能看到12×8px箭头，当前值与箭头不重叠。 |
| 150%系统缩放 | 箭头轮廓清楚，分隔线不糊，弹层不被屏幕裁切。 |
| 长日期 | 控件省略、弹层扩到推荐360px、hover显示完整日期范围。 |
| 长广告组合 | 弹层按内容扩宽且不超过440px，名称和计数不重叠。 |
| 选择广告组合 | 广告活动与广告组选项同步收窄，每个可点击值匹配数大于0。 |
| 放宽某条件 | 其余字段候选项增多，已选值和页面滚动位置保持。 |
| 唯一候选 | 显示全部加唯一候选，不自动替用户选择。 |
| 当前字段无值 | 显示`当前范围无可选项`并disabled，其他字段继续工作。 |
| 关联更新失败 | 恢复选择前状态，旧结果继续可读，不出现空白列表。 |
| 减少动态效果 | 箭头、弹层和tooltip立即切换，无旋转、淡入或滚动动画。 |

## 给code-writer的增量说明

- 只扩展现有筛选组合框及候选数据查询，不修改页面结构、字段名称、统计公式和橙绿token。
- 箭头使用共享矢量资源和语义颜色，不使用文字字符或依赖不同Windows主题的原生箭头。
- 级联查询必须按排除自身条件计算，每个候选附带匹配记录数，并用一次结果快照更新6个筛选和主页面。
- 更新候选模型时保留当前选择、焦点和滚动位置，禁止通过清空再逐项添加造成闪烁。
- 需要覆盖箭头缩放、长文本、弹层边界、分面计数、连续选择、查询失败和键盘操作测试。
