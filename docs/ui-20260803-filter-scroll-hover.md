## 结论

本轮不改左侧导航、顶部文件区、橙绿语义和页面功能边界。在搜索及AI操作区下方恢复独立筛选栏，加入日期、币种、广告组合、广告活动、广告组、搜索词类型和重置筛选。主工作区改为页面级纵向滚动，取消必须塞进一屏的高度目标。Top10卡片增高，并为每一行条形图增加包含完整词元和六项指标的悬停浮层。表格保留内部滚动，最小高度提高到能连续比较至少11行数据。

## Design Thinking

| 项目 | 决策 |
|---|---|
| Purpose | 让查看广告搜索词数据的用户先限定业务范围，再连续查看KPI、Top10和明细，避免在高密度页面里反复猜测当前数据口径。 |
| Tone | 克制、清楚的Windows业务分析工具。参考广告报表的操作密度，但保留项目现有近白底、橙色操作和绿色数据强调。 |
| Constraints | PySide6桌面应用；左栏固定且可收起；主窗口最小1080×700；筛选选项可能达到数千项；Excel部分可选字段可能缺失；Top10和7列表格使用同一当前范围；正文及交互满足工程底线。 |
| Differentiation | 页面从范围、指标、排行到明细形成连续纵向阅读；绿色条形图悬停后直接显示该词元完整指标，无需去表格找同一行。 |

## frontend-design取舍

### 采用的原则

| 维度 | 本轮决策 | 依据 |
|---|---|---|
| Typography | 保留项目字体，只重新分配现有`brandTitle`、`pageTitle`、`sectionTitle`、正文、`mutedLabel`和数字层级。 | 项目现状优先；通过字号、字重和行高处理密度，不在局部改字体家族。 |
| Color & Theme | `accent-primary`橙色继续表示搜索、导入和当前位置；`data-accent`绿色继续表示数据图形和AI操作；中性色承担大面积背景。 | 主色和强调色职责清楚，符合frontend-design关于明确色彩关系的建议。 |
| Motion | 只在筛选结果更新、下拉展开和图表tooltip出现时使用`motion-fast`；不做页面入场表演。 | 动效集中在高价值反馈，避免数据页分散注意力。 |
| Spatial Composition | 使用受控密度和稳定的单列纵向阅读。筛选栏独立成区，图表与表格获得更高的固定最小高度。 | 用户允许页面向下延展，留白和连续阅读比一屏塞满更重要。 |
| Backgrounds & Details | 继续用近白根背景、白色卡片、细分隔和交替的浅橙及浅绿数据卡，不新增装饰纹理。 | 现有桌面工具靠信息关系建立层级，装饰不能干扰数字。 |

### 不直接照搬的网页建议

- 不更换`Microsoft YaHei UI`和`Segoe UI`。frontend-design偏好有性格的展示字体，但项目已确定Windows桌面字体，局部替换会造成中文回退、安装依赖和度量变化。
- 不使用非对称重叠、斜线、破格网格。筛选、指标和表格要求快速对齐比较，规则网格更适合本场景。
- 不使用渐变网格、噪点、玻璃效果、强阴影和自定义光标。现有橙绿配色与浅色QSS已经形成稳定语言。
- 不做滚动触发入场、整页stagger或夸张hover。桌面数据刷新频繁，动画只服务状态确认，并尊重减少动态效果设置。
- 不追求网页海报式的强烈记忆点。记忆点落在橙色业务操作、绿色排行和从筛选到明细的连续关系上。

## 数据范围与筛选口径

### 字段来源

| 界面标签 | 数据来源 | 展示与空值规则 |
|---|---|---|
| 日期 | Excel列`日期范围` | 展示源值；可解析日期按最近到最早排列，不可解析值按本地文字顺序排列。空值不作为选项，但在全部范围中保留。 |
| 币种 | Excel列`预算货币` | 去重后展示源值，例如USD；空值不作为选项。 |
| 广告组合 | Excel列`广告组合名称` | 去重后展示完整名称。 |
| 广告活动 | Excel列`广告活动名称` | 去重后展示完整名称。 |
| 广告组 | Excel列`广告组名称` | 去重后展示完整名称。 |
| 搜索词类型 | 程序派生 | 固定为全部、关键词、ASIN。完整搜索词经规范化后，整体匹配ASIN规则时归入ASIN，其余归入关键词。 |

- 五个Excel筛选项均为单选精确匹配。不同字段之间取交集。
- 筛选项选项来自当前导入批次的完整数据，不随其他筛选动态删减，避免已选值突然消失。
- 筛选与辅助搜索同时存在时，先应用筛选，再在筛选结果内执行词元或连续词组搜索。
- KPI、Top10和7列表格使用相同筛选、搜索和排序状态。排序只改变Top10和表格顺序，不改变KPI汇总值。
- 切换筛选不得触发AI请求。
- 项目现有规则规定，无搜索时AI推荐使用整份数据，有搜索时使用全部匹配记录。本轮不擅自改变该口径。筛选是否约束AI范围列入待决策项；未确认前，AI范围提示必须明确说明页面筛选不影响AI推荐。

- 顶部`appHeader`固定62px，不进入页面滚动。
- 左侧栏位于顶部栏下方，展开宽166px，收起宽64px，高度等于窗口剩余高度；侧栏自身不随分析页滚动。

- 页面滚动条使用项目现有10px滚动条规格。拖动条、鼠标滚轮、触控板和PageUp、PageDown均可操作。

### 嵌套滚动规则

- 页面负责卡片之间的纵向移动；表格负责500项及更多结果的内部滚动。
- 鼠标位于表格数据区时先滚动表格；到达表格顶端或底端后，继续滚轮应传递给页面，避免用户被困在内层滚动区。
- 鼠标位于表头、表格工具栏、图表或空白处时滚动页面。
- 表格仅在用户主动拖窄数值列后才允许内部横向滚动；默认列宽必须在内容净宽内完整显示7列。
- 侧栏展开收起不重置页面或表格滚动位置。
- 应用筛选后页面滚动位置保持不变；若当前视口已低于结果内容底部，则平滑校正到最近有效位置，使用`motion-fast`。减少动态效果时立即校正。

### 大量选项下拉交互

- 每个Excel字段选项不超过20项时，直接显示列表；超过20项时，下拉顶部固定显示搜索输入和选项总数。
- 下拉宽度取控件宽度与320px的较大值，最大宽420px；最大高度320px。弹层必须限制在当前屏幕可见区域内。
- 第一项固定为全部，随后显示去重后的有效值。当前选中项带勾选图标和浅橙背景，键盘焦点使用独立focus ring。
- 搜索采用不区分大小写的包含匹配。输入只过滤下拉候选，不立即改动页面数据；Enter选择当前高亮项，Esc关闭并保留原选择。
- 长列表只渲染可见项或使用Qt模型视图复用行，禁止一次创建数千个独立控件。滚动到底可继续读取本地模型，不发起网络请求。
- 每行高36px，左右内边距10px。名称单行省略，悬停tooltip显示完整名称。
- 打开下拉后焦点进入搜索输入；上下方向键移动，Home和End跳转，Enter确认，Esc关闭。关闭后焦点返回原筛选控件。
- 导入完成时一次读取本批次选项并缓存。重新导入成功后清空旧筛选和旧缓存，再加载新选项。
- Excel缺少某个可选列或整列均为空时，对应控件disabled，控件值显示`源表无此字段`，tooltip说明来源列名。其他筛选仍可使用。

### 筛选组件四态

| 状态 | 规格 |
|---|---|
| Default | 白色背景、现有输入边框、正文色选项值、右侧下拉图标。 |
| Hover | 使用现有`surface-hover`，边框提高一级对比，`motion-fast`。 |
| Active或Focus | 2px橙色focus ring，边框变化不得引发布局跳动；下拉图标旋转只在未启用减少动态效果时使用。 |
| Disabled | 使用现有disabled背景与文字，保留label和原因tooltip，不隐藏控件。 |

## KPI区

- 继续使用5列等宽布局，顺序为曝光量、点击量、订单数、点击率、转化率。
- 1280×820高80px，1440×900高84px；卡片间距8px。
- 保留橙绿交替顶部色线，但色线只表示视觉节奏，不承载正负或好坏语义。
- KPI标题使用12px层，数值使用现有19px`kpi=true`；数值过长时使用既有紧凑variant，不压缩卡片间距。
- 筛选无结果时计数类显示0，点击率和转化率显示空值符号，并在tooltip解释分母为0。

## Top10图表

### 卡片与绘图区

- 1280×820卡片高284px，1440×900卡片高300px，8px圆角，无常规阴影。
- 卡片内边距上12px、右16px、下12px、左14px。
- 标题区高28px，标题为`词元Top10·点击量`等当前排序维度；右侧显示`当前筛选3项`或`整份数据`。
- 1280下绘图区高232px，1440下绘图区高248px。10行必须全部可见，不裁切第10项。
- 行高20px或21px，行间距3px，条轨高10px，圆角沿用控件圆角比例。
- 词元标签区在1280下宽168px，在1440下宽190px；标签右对齐，过长右侧省略，hover仍显示完整tooltip。
- 数值区最小92px，使用`Segoe UI`等宽数字并右对齐。百分比保留2位小数，计数使用千分位。
- 条轨使用中性浅背景，填充使用`data-accent`绿色。排序维度只有一个数据系列，不新增图例色块；标题已经承担图例作用，辅助说明写明条长代表当前排序维度。

### Tooltip触发与内容

- 整行命中区均可触发，不要求精确停在10px高的色条上。命中区包含词元标签、条轨和数值。
- 鼠标停留160ms后显示，使用`motion-fast`淡入；离开命中行或图表后160ms淡出。浮层距指针12px，并限制在图表或屏幕可见范围内。
- tooltip宽度240至320px，内边距10px，6px圆角，深色背景配浅色文字。不得遮挡当前行的词元标签；空间不足时优先放到指针左上方。
- 浮层内容固定如下：

```text
sandals
第1名 · 按点击量排序
点击量 140,002
匹配记录 46,557 · 曝光量 25,658,451
订单数 11,108 · 点击率 0.55% · 转化率 7.93%
范围：搜索 sandals women · 已应用3项筛选
```

- 第一行为完整词元或完整搜索词，不省略。第二行说明名次与当前排序维度。第三行突出当前排序指标。第四、五行补全其余指标。最后一行显示搜索和筛选范围；无搜索或无筛选时用`整份数据`。
- 图表可获得键盘焦点；上下方向键切换活动行，并显示与hover相同的tooltip。可访问名称包含Top10标题，描述包含当前排序维度和结果数量。
- tooltip只用于补充，条末端仍保留当前排序指标数值，用户不悬停也能比较。

### 图表四态与数据状态

| 状态 | 规格 |
|---|---|
| Default | 绿色条、浅色轨道、完整10行或实际结果行数。 |
| Hover或Focus | 当前行使用`data-accent-soft`浅绿行底，色条加深一级，显示tooltip。 |
| Active | 图表无点击选择行为；键盘活动行等同focus，不制造永久选中态。 |
| Disabled | 数据加载期间不响应hover，保留原图并加轻遮罩和进度说明。 |
| Loading | 查询超过200ms后显示`正在应用筛选…`和不确定进度指示，保持卡片高度，旧数据降为次要但不清空。 |
| 筛选无结果 | 中央显示筛选图标、`没有匹配当前筛选的数据`和`重置筛选`次操作。 |
| 当前指标全为0 | 显示词元标签和0值，条轨不填充；顶部说明`当前范围的该指标均为0`，不误报为无数据。 |
| Error | 显示错误图标、简短原因和`重试`，错误不能只用红色文字。 |

## 7列表格

### 尺寸与结构

- 1280×820最小高448px，1440×900最小高480px。用户放大窗口时，表格优先获得额外高度，上限不限制。
- 工具栏高52px，表头高36px，数据行高30px。1280下至少连续显示11行，1440下至少连续显示12行；随后在表格内部滚动。
- 工具栏左侧为`词元排行`、总数、搜索及筛选摘要；右侧为加载更多和加载全部。
- 保留7列：词元、匹配记录数、曝光量、点击量、订单数、点击率、转化率。
- 词元列左对齐并吸收剩余宽度。6个数字列使用`Segoe UI`等宽数字并右对齐。默认列宽必须完整容纳常见数值和表头。
- 词元超长时单行右侧省略，hover显示完整值；双击仍查看匹配的完整搜索词。
- 用户主动调整列宽后保留其偏好；切换筛选和排序不得重置列宽。

### 表格四态与数据状态

| 状态 | 规格 |
|---|---|
| Default | 白底与现有浅交替行，细横分隔，数字右对齐。 |
| Hover | 当前行使用中性hover背景，不改变文字宽度。 |
| Active或Selected | 使用现有浅橙选中背景，并同时保留左侧焦点标记；不能只靠颜色。 |
| Disabled | 加载期间表格不可选，旧内容降为次要，工具栏显示进度。 |
| Loading | 筛选查询超过200ms后保留旧行并显示顶部细进度条；加载更多显示已加载数量。 |
| 筛选无结果 | 表体显示`没有匹配当前筛选的数据`、已应用条件摘要和`重置筛选`。表头保留，方便理解数据结构。 |
| 搜索无结果 | 显示`没有找到包含〈搜索内容〉的记录`，提供`清空搜索`，不自动重置筛选。 |
| Error | 保留上一次成功结果并在工具栏下显示错误条，包含错误图标、原因和重试。 |

## 空、加载与反馈状态

### 未导入数据

- 沿用既有空导入页，不显示筛选、KPI、Top10或空表格。
- 来源说明继续列出读取第一个工作表、4个必需列和导入替换规则。

### 导入数据中

- 顶部显示现有进度条，批次栏写`正在读取Excel…`和文件名。
- 搜索、筛选、排序、加载、AI和重复导入全部disabled；侧栏可见但按项目并发规则阻止危险切换并说明原因。
- 导入成功后重建筛选选项并回到全部状态；导入失败时保留旧数据、旧筛选和旧滚动位置。

### 应用筛选中

- 用户选择后立即更新控件文字，160ms内合并连续变化。
- 查询未超过200ms时不显示spinner，避免闪烁；超过200ms后KPI、图表和表格显示统一加载状态。
- 新结果一次提交到KPI、Top10和表格，禁止三个区域先后显示不同范围。
- 完成后状态栏显示`已应用3项筛选·48,690个词元·按点击量排序`。

### 筛选无结果

- KPI计数归0，比例为空值；Top10和表格分别显示同一无结果说明。
- 筛选栏保留当前值并突出`重置筛选`，不自动撤销用户条件。
- 本次推荐要求和生成AI推荐按钮是否可用仍按既有AI范围规则处理，旁边必须清楚显示页面结果为空并不代表AI范围为空。

## 交互与动效

- 筛选选择、重置、搜索和排序都只触发本地查询，不触发AI。
- 筛选结果切换使用`motion-fast`，只做内容透明度轻微变化，不让卡片上下移动。
- 下拉展开、tooltip出现和错误条出现使用160ms ease-out；关闭使用160ms ease-in。侧栏保持`motion-panel`180ms ease-in-out。
- 异步查询超过200ms才显示loading，避免短查询闪烁。
- 尊重减少动态效果设置：取消图标旋转、透明度和滚动校正动画，状态立即切换。
- 排序、筛选、搜索更新后，Top10和表格使用同一结果快照。图表条长可在160ms内过渡，文字数值立即更新；减少动态效果时条长立即变化。

## 工程正确性自检

- 可访问性：正文对比度保持至少4.5∶1，大字至少3∶1；所有筛选label可见；focus ring独立可辨；选中、错误和当前页均不只依赖颜色。
- 触控与鼠标：桌面控件高40px，图表整行作为hover命中区；最小窗口不出现密集小图标按钮。
- 表单：下拉有可见label；源表缺字段时就近说明；搜索框有可访问名称；错误在对应控件或卡片附近显示。
- 导航：左栏固定，当前位置继续使用橙色线、图标和文字；侧栏收起后保留tooltip。
- 响应式：1280和1440单行筛选；净宽低于1040px时筛选两行；页面无横向滚动。
- 中文断行：卡片标题不允许单字孤行；筛选值和词元使用省略加tooltip，不在窄控件内强制断字。
- 装饰避让：Top10标题、范围说明、词元标签、条轨和数值分配独立矩形，不相互覆盖。
- 动效：状态切换160ms，侧栏180ms，均位于150至300ms范围；支持减少动态效果。
- 图表：当前指标由标题说明；tooltip齐全；不只靠颜色；空、错、loading和全0状态均有方案。
- 反馈：筛选、下拉、按钮、图表行和表格行均定义默认、hover、active或focus、disabled；查询有loading反馈。

## 反AI套路自检

- 字体沿用项目既有Windows中文字体，不在本轮局部替换。此项与frontend-design偏好有冲突，项目一致性优先。
- 配色只有项目现有橙、绿和语义状态色，没有紫色渐变白底，没有新增同义色。
- 布局不是三等分卡片或Hero数字大屏。筛选、KPI、排行和明细按业务分析顺序排列。
- 不使用玻璃拟态、ghost card、纹理背景、装饰性渐变和大阴影。
- 页面特征来自广告报表筛选字段、同范围联动和词元指标tooltip，不靠通用后台模板装饰。

## 待决策项

1. 页面筛选是否限制AI推荐范围。项目现有硬规则是无搜索时使用整份数据、有搜索时使用全部匹配记录。本方案暂不改变；若筛选也要约束AI，需要单独更新数据口径、确认弹窗、费用范围说明和测试。
2. 日期源字段目前是Excel的`日期范围`，不是独立开始日期和结束日期。本轮按单选源值设计；若要任意日期区间，需要先确认源字段格式和跨范围计算规则。
3. 筛选下拉按单选设计，与参考图一致。若业务需要多选，控件高度、选项摘要、查询参数和重置行为都需另行定义。
4. frontend-design建议更有性格的字体，但项目现有`Microsoft YaHei UI`和`Segoe UI`更符合Windows兼容要求。本轮不更换；字体升级应作为全应用设计系统任务处理。
