# 词元分析器正式UI方案

日期：2026-08-03

## 设计方向

方向：精密数据工作台。

界面参考专业投放分析工具和桌面表格软件的高信息密度，但不做传统后台式侧边栏。用户打开后先看到数据批次、搜索入口和核心指标，主要空间始终留给词元表格。主色使用冷静的深蓝，AI操作使用琥珀色作为第二强调色，使本地统计与付费模型调用在视觉上有明确区分。

## 页面层级

1. 顶部品牌栏：产品名、当前数据文件、导入Excel、模型设置。
2. 分析控制卡：搜索、清空搜索、AI推荐模式、本次推荐要求、当前权重摘要、手动触发AI推荐。
3. 指标带：数据记录数、曝光量、点击量、订单数、点击率、转化率。
4. 数据表卡：当前视图标题、排序维度、加载更多、加载全部和可拖动表格。
5. 底部状态栏：当前任务状态和统计口径。

## 视觉规格

- 窗口默认1280×820，最小1080×700。
- 背景：`#F3F6FA`。
- 主文字：`#172033`，次文字：`#68758A`。
- 主操作：`#176BCE`，悬停`#0F5DB8`。
- AI操作：`#D97706`，悬停`#B85F05`。
- 卡片：白色，1像素`#DDE4EE`边框，10像素圆角。
- 正文字体：Microsoft YaHei UI；数据值使用Segoe UI，形成数字节奏。
- 表头使用浅蓝灰底色，选中行使用低饱和蓝色，不依赖颜色表达唯一状态。

## 交互状态

- 主按钮、次按钮和AI按钮具有默认、悬停、按下、禁用四种状态。
- 导入和AI推荐期间按钮禁用，进度条或状态文字同步变化。
- API调用只有点击AI推荐词元或测试连接才触发。
- 当前模型、推荐模式、权重和本次推荐要求在控制区直接可见。
- 表格7列均支持拖动，默认宽度自动排好。

## 弹窗

- 模型设置、权重设置、本次推荐要求和推荐结果共享同一套标题、输入框、按钮和表格样式。
- 付费相关测试连接旁保留费用提醒。
- 密钥字段保持密码模式，界面不显示明文。
