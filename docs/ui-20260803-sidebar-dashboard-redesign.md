## 结论

新正式UI使用左侧纵向导航、顶部文件信息、KPI、Top10水平条形图和底部7列表格。分析页不再采用上一版顶部工具条结构。橙色只承担主操作和当前位置，绿色承担数据强调；模型判断功能及其卡片、按钮、置信度、原因和保存判断全部删除。

主页面保留辅助搜索、本次推荐要求、生成AI推荐、排序、加载更多和加载全部。模型设置、推荐模式切换和自定义权重编辑全部进入设置页，分析页只显示当前推荐模式及六项权重摘要。

## 设计依据

### Design Thinking

| 项目 | 决策 |
|---|---|
| Purpose | 让编程小白导入Excel后直接浏览词元排行，通过同一排序维度同时查看KPI、Top10和明细表，必要时搜索或手动生成AI推荐。 |
| Tone | 清楚、克制的中文桌面数据看板，接近参考图中的白底业务工具，不做后台管理系统的大面积深色块。 |
| Constraints | PySide6桌面应用；默认1280×820；最小1080×700；左侧导航可展开和收起；首页默认500项；7列可拖动；AI联网且可能收费；导入新数据会替换旧数据。 |
| Differentiation | 一个排序维度同时驱动Top10图和明细表，用户从汇总、排行到原始匹配词只需沿页面向下阅读。 |

### frontend-design五项决策

| 维度 | 决策 | 原因 |
|---|---|---|
| Typography | 沿用项目现有`Microsoft YaHei UI`，数字继续用`Segoe UI`并使用等宽数字。 | 与中文Windows桌面环境和现有应用一致。 |
| Color & Theme | 页面使用`surface-base`近白背景、`surface-card`白色卡片、`accent-primary`橙色主操作和`data-accent`绿色数据强调。 | 直接沿用两张参考图的视觉关系，避免蓝色旧方案继续混入。 |
| Motion | 侧栏展开收起使用`motion-fast`；图表切换只做短暂长度过渡；其他状态用文字和进度反馈。 | 确认状态变化，不让数据页出现无关运动。 |
| Spatial Composition | 左侧导航固定；右侧从文件状态、操作区、KPI、Top10到表格形成单向阅读顺序。 | 符合参考图，也符合导入后查看排行的核心任务。 |
| Backgrounds & Details | 使用近白底、细分隔线、轻卡片和单色绿色条形图，不使用渐变、玻璃效果、噪点或装饰纹理。 | 参考图依靠信息排布而非装饰建立层级。 |

## 项目设计语言映射

本次是用户明确要求的正式UI重设计，允许页面主色从旧蓝色改为参考图橙色。仍沿用项目的Qt QSS、objectName和动态属性写法，不引入新UI库。

| 类别 | 现状或参考来源 | 新方案取值 |
|---|---|---|
| 样式系统 | `theme.py`集中QSS，使用类型选择器、objectName和动态属性 | 保持，新增语义角色，不把颜色散落到组件源码。 |
| 基础背景 | 参考图为白色工作区，项目有浅灰蓝根背景和白卡片 | 新增`surface-base`近白暖灰，卡片复用`surface-card`白色；禁止纯白铺满整个窗口。 |
| 主操作 | 参考图使用橙色导入和搜索按钮 | 将`role=primary`用于橙色实心按钮；hover、active、disabled各有状态。 |
| 数据强调 | 参考图使用绿色图表、趋势和Excel语义 | 新增`role=data`或`dataAccent`，用于条形图、Excel图标、数据状态和少量强调。 |
| 当前位置 | 参考图使用橙色竖线和橙色文字 | 新增`navItem[current=true]`，同时使用竖线、图标和文字，不只靠颜色。 |
| 次操作 | 项目已有`role=quiet` | 继续用于本次推荐要求、加载更多、加载全部和取消。 |
| 危险与错误 | 项目已有消息框语义 | 使用`semantic-error`，必须配错误图标和文字。 |
| 字体 | 项目已有`Microsoft YaHei UI`和`Segoe UI` | 保留，不新增字体依赖。 |
| 字号层级 | 项目已有`brandTitle`、`sectionTitle`、`sectionCaption`、`mutedLabel`、`kpi=true` | 继续使用这些语义层级，新增`pageTitle`和`chartValue`时按现有梯度补一档。 |
| 圆角 | 项目卡片和控件已有圆角 | 看板卡片统一8px，输入和按钮统一6px；不混用多套圆角。 |
| 边框 | 项目已有浅色细边框 | 统一复用`border-subtle`；导航和KPI优先用背景差、留白区分。 |
| 阴影 | 当前无明确阴影token，参考图主要靠边框 | 不新增大阴影；弹窗可使用系统窗口阴影。 |
| 动效 | 当前无动效token | 新增`motion-fast`160ms ease-out和`motion-panel`180ms ease-in-out。 |
| 表格 | 项目已有表头、斑马纹、选中态和滚动条 | 保留基础能力，视觉改成参考图的白底细分隔线，数字右对齐。 |

## 功能边界

### 分析页保留

- 辅助搜索词元或连续词组。
- 当前文件名和导入记录数。
- 导入新数据。
- 当前数据范围KPI。
- 当前排序维度和Top10水平条形图。
- 本次推荐要求。
- 手动生成AI推荐。
- 当前推荐模式和六项权重只读摘要。
- 加载更多500项、加载全部。
- 7列表格及可拖动列宽。

### 设置页承接

- 模型服务商、API地址、模型名称和API密钥。
- 测试连接。
- 均衡推荐、流量增长、转化优先和自定义权重模式切换。
- 六项自定义权重编辑、合计校验和恢复均衡权重。

### 完整删除

以下内容不得出现在分析页、设置页、导入记录页、弹窗或状态栏：

- 模型判断按钮。
- 模型判断结果卡片。
- 有意义的连续词组判断。
- 判断置信度。
- 判断原因。
- 保存判断按钮。
- 已保存判断记录。

AI推荐是独立功能，不使用判断、置信度、保存判断等旧称呼。

## 信息层级

| 层级 | 内容 | 视觉处理 |
|---|---|---|
| 第一层级 | 当前文件、KPI、Top10、7列表格 | 文件名使用`pageTitle`；KPI值和图表值使用数据字体；表格占底部最大连续宽度。 |
| 第二层级 | 排序、辅助搜索、本次推荐要求、生成AI推荐、导入新数据 | 导入和生成AI推荐使用`role=primary`；搜索和排序使用描边控件。 |
| 第三层级 | 当前推荐模式、六项权重、AI范围、费用提示、加载状态、统计口径 | 使用`sectionCaption`或`mutedLabel`，关键费用文字配联网图标。 |

## 应用外壳

### 展开态

- 侧栏宽度184px，最小不缩窄。
- 顶部品牌区高度58px，左侧显示应用图标和`词元分析器`，右侧为收起按钮。
- 导航从品牌区下方16px开始，每项高度48px，左右内边距16px，项目间距8px。
- 导航顺序固定为分析、导入记录、设置。
- 当前项左侧显示3px橙色竖线，图标和文字使用`accent-primary`，背景使用`accent-primary-soft`。
- 侧栏底部显示当前版本号，使用`mutedLabel`。
- 收起按钮tooltip为`收起导航`，可用Ctrl+B切换。

### 收起态

- 侧栏宽度64px。
- 品牌区只保留应用图标和展开按钮，不显示应用名、版本号和导航文字。
- 导航图标按钮为44×44px，在64px栏内水平居中。
- 当前项仍保留左侧3px橙色竖线、浅橙背景和橙色图标。
- 每个图标hover或键盘focus时显示tooltip：分析、导入记录、设置。
- 展开与收起使用`motion-panel`，内容区同步调整，不出现中间白缝或横向滚动。
- 用户手动选择的状态写入本地设置，下次启动恢复；窗口缩放不擅自改写用户选择。

### 导航状态

| 状态 | 规格 |
|---|---|
| 默认 | 深色线性图标加主文字，无背景。 |
| Hover | 使用`surface-hover`，160ms ease-out。 |
| Active | 使用`surface-pressed`，图标和文字保持可读。 |
| Current | 左侧橙色竖线、浅橙背景、橙色图标和文字。 |
| Focus | 2px焦点环，不能只依赖橙色竖线。 |
| Disabled | 导航本期无disabled态；页面加载中仍可切换，正在导入或AI请求时按并发规则阻止并说明。 |

## 顶部文件栏

顶部文件栏属于右侧工作区，不是横跨全页的工具条。所有页面都保留。

### 有数据

- 高度58px。
- 左侧依次为文件图标、文件名、分隔点、`180,456条记录`。
- 文件名可用宽度随窗口变化，采用中间省略；tooltip显示完整路径。
- 记录数不可省略，使用千分位。
- 右侧只保留`导入新数据`橙色主按钮。
- 不显示模型状态、模型设置、权重编辑或其他工具按钮。

### 无数据

- 左侧显示灰色状态点和`未导入数据`。
- 右侧仍显示`导入新数据`，与空状态中央的`选择Excel`触发同一流程。

### 导入新数据确认

点击按钮后先显示确认弹窗，再打开文件选择器。弹窗内容包含当前文件名、当前记录数和明确文字：`导入成功后会替换当前数据；导入失败会保留当前数据。`

按钮为`取消`和`继续选择Excel`。导入运行期间禁用导航切换、搜索、AI推荐和重复导入；主窗口关闭时说明任务仍在运行，不直接退出。

## 分析操作区

分析操作区为两行扁平卡片，不做大标题或多层工具条。

### 第一行

- 可见标签`辅助搜索`。
- 搜索输入框为弹性宽度，placeholder为`输入词元或连续词组，例如sandals women`。
- 查询按钮使用描边次操作，Enter触发查询。
- 输入框自带清除图标；搜索生效后，清除即返回词元排行。
- 可见标签`排序`，下拉项为点击量、曝光量、订单数、点击率、转化率、匹配记录数。
- `本次推荐要求`使用`role=quiet`。
- `生成AI推荐`使用`role=primary`和联网图标。

### 第二行

- 左侧显示`当前推荐：均衡推荐`及六项权重摘要，只读，不在主页面编辑。
- 六项顺序固定：订单、点击、曝光、转化率、点击率、匹配记录数。
- 右侧紧邻AI按钮位置显示`范围：整份数据`和`联网调用，可能产生模型费用`。
- 搜索生效后范围改为`范围：搜索词〈内容〉的全部匹配记录`，明确不受当前显示100行限制。
- 长权重摘要可末尾省略，tooltip显示完整六项；费用提示不得省略。

### AI请求确认

点击`生成AI推荐`后显示确认弹窗，必须列出服务商、模型、当前范围、推荐模式、六项权重摘要和可能计费提示。按钮为`取消`和`确认并生成`。确认前不发送请求。

运行时主按钮改为`正在生成…`，禁用导入、查询、排序、设置切换和重复AI请求；第二行显示当前阶段。成功后打开AI推荐结果弹窗，本次推荐要求自动清空；失败后保留要求并显示重试入口。

## KPI卡规格

- 固定5张：曝光量、点击量、订单数、点击率、转化率。
- 顶部文件栏已经显示源文件记录数，搜索结果的匹配记录数显示在表格标题旁，不重复增加第6张卡。
- KPI展示当前数据范围汇总。未搜索时为整份数据，搜索后为全部匹配记录，不受表格当前显示行数限制。
- 所有卡片使用同一`data-accent`顶部细线；橙色不用于随机区分KPI。
- 标签复用`mutedLabel`，数值复用`kpi=true`和数据字体。
- 本期没有历史同期数据，不显示参考图中的上涨箭头、环比和较上期，避免制造不存在的比较。
- CTR说明为点击量÷曝光量，CVR说明为订单数÷点击量。分母为0时显示项目现有空值符号，tooltip说明原因。

| 状态 | 规格 |
|---|---|
| 默认 | 白底、绿色顶部细线、深色数字。 |
| Hover | 无点击功能，不做悬浮抬升；仅在有tooltip时显示指针提示。 |
| Active | 不适用。 |
| Disabled | 无数据时不显示KPI卡，直接进入空数据态。 |
| Loading | 保留卡片尺寸，数值区域显示中性占位条和`正在计算`。 |
| Error | 显示错误图标和`暂时无法计算`，不显示伪造的0。 |

## Top10水平条形图

### 数据规则

- 图表标题为`词元Top10`；搜索结果页改为`完整搜索词Top10`。
- 副标题显示当前维度，如`按点击量从高到低`，承担单系列图例作用。
- 数据来自当前完整范围，不受已加载500项或100项限制。
- 排序切换后图表和表格立即使用同一维度重新排序。
- 图表始终只显示一个系列，所有条形统一使用`data-accent`绿色。
- 切换维度不改变颜色，避免用户误以为颜色代表另一组数据。
- 点击率或转化率为空的项目不进入对应Top10；有效项目不足10个时如实显示剩余数量。

### 图形规格

- 图表卡8px圆角，使用`surface-card`和`border-subtle`。
- 左侧标签区在1280宽时180px，在1080宽时150px；长词元末尾省略，tooltip显示全文。
- 条形高度10px，行间距6px；1080紧凑态条形高度8px，行间距5px。
- 条形从统一0基线开始，禁止截断横轴制造差异。
- 横轴显示3至5个刻度，使用浅色网格线；不显示纵轴轴线。
- 曝光量、点击量、订单数和匹配记录数使用千分位整数。
- 点击率和转化率使用两位百分比。
- 数值放在条形末端外侧；空间不足时贴近右边界，但不能覆盖标签或被裁切。
- Hover条形使用同色较深状态，tooltip只显示完整名称、当前指标和值。
- 不显示多系列图例、渐变条、堆叠条、环比箭头或第二坐标轴。

### 图表联动

1. 用户切换排序下拉框。
2. 下拉框进入loading，其他排序触发暂时disabled。
3. KPI范围不变，Top10标题、副标题、横轴格式、条形和值更新。
4. 表格按同一维度降序刷新，当前列表头显示降序箭头。
5. 焦点返回排序下拉框，状态栏读出`已按点击率更新图表和表格`。

更新过渡使用`motion-fast`，先更新刻度和标签，再改变条形长度；Windows减少动画开启时直接更新。总时长不超过160ms，不使用逐条错峰入场。

### 图表状态

- Loading：保留标题，绘图区显示10条中性占位线和`正在更新Top10…`。
- Empty：显示`当前范围没有可用于此指标的数据`，提供其他排序下拉框，不显示空坐标轴。
- Error：显示错误图标、简短原因和`重试`，表格保留上一次成功数据。
- Focus：图表容器可通过Tab获得焦点；左右键或上下键在10项间移动，读屏文本包含排名、名称、指标和值。

## 7列表格

### 结构

排行页列顺序：词元、匹配记录数、曝光量、点击量、订单数、点击率、转化率。

搜索结果页仅将第一列改为完整搜索词，其余6列不变。

### 表格工具栏

- 左侧显示`词元排行`或`搜索结果：〈查询词〉`。
- 标题旁显示`共48,690个词元`或`共N条匹配记录`。
- 右侧依次显示`已显示500项`、`加载更多500项`和`加载全部`。
- `加载全部`点击前显示总项数确认；超过5000项时明确说明内存和等待成本。
- 排序只在分析操作区保留一个入口，表格工具栏不重复放第二个排序下拉框。

### 默认列宽

- 第一列28%。
- 匹配记录数13%。
- 曝光量15%。
- 点击量12%。
- 订单数11%。
- 点击率10.5%。
- 转化率10.5%。
- 所有7列可拖动；只有用户主动调整后才保留其宽度。
- 新数据批次首次显示使用默认比例；双击列分隔线自动适应内容。
- 第一列左对齐；数值列及其表头右对齐，使用数据字体和等宽数字。
- 默认不出现无意义横向滚动；用户把列拉宽超过视口后才允许横向滚动。

### 行与选择

- 行高28px，表头32px。
- 整行单选，斑马纹保持低对比。
- 排行页双击或按Enter查看该词元的完整搜索词；搜索结果页不再次触发搜索。
- 当前排序列表头显示文字和降序箭头，不能只靠绿色或橙色区分。
- 长文本末尾省略，tooltip显示全文。
- 数字不省略，保留千分位；比率保留两位百分比。

### 表格状态

| 状态 | 规格 |
|---|---|
| 默认 | 白底细分隔线，数字右对齐。 |
| Hover | 整行使用`surface-hover`。 |
| Selected | 整行使用`data-accent-soft`并保留3:1焦点边界。 |
| Focus | 表格外框和当前行焦点同时可见。 |
| Loading more | 保留现有行，底部显示`正在加载更多…`，两个加载按钮disabled。 |
| Empty search | 显示`没有找到包含〈查询词〉的完整搜索词`和`返回词元排行`。 |
| Error | 保留上次结果，工具栏下显示错误图标、原因和重试。 |

## 导入记录页

导入记录页使用同一侧栏和顶部文件栏。页面标题为`导入记录`，主体为单张表格，列为导入时间、文件名、导入记录数、跳过空搜索词、结果。

- 记录只用于查看，不提供恢复旧数据、重新导入或删除按钮。
- 当前批次增加`当前数据`文字标签，使用图标加文字，不只用绿色。
- 没有记录时显示文件历史图标、`还没有导入记录`和`导入Excel`。
- 若当前后端尚未保存历史导入事件，应把数据支持列为实现依赖，不用当前metadata伪造多条记录。

## 设置页

设置页使用同一侧栏和顶部文件栏。内容宽度不超过760px，靠左排列，不做三列设置卡。

### 模型设置

- 可见标签：服务商、API地址、模型名称、API密钥。
- API密钥默认隐藏，提供显示和隐藏按钮。
- API地址在携带密钥时必须为HTTPS；localhost、127.0.0.1和::1可用HTTP。
- `测试连接`旁持续显示`会发送一次短请求，云服务商可能计费`。
- 测试期间按钮改为`测试中…`，禁用关闭设置页和重复测试。
- 保存配置不联网，保存按钮使用`role=primary`。

### 推荐设置

- 模式使用单选列表：均衡推荐、流量增长、转化优先、自定义权重。
- 选择前三种模式时显示六项只读权重。
- 选择自定义权重时显示6个带可见label的整数百分比输入框。
- 合计状态显示`当前合计100%，可以保存`、`还差N%`或`超出N%`，使用图标和文字。
- 合计不是100%时保存disabled。
- `恢复均衡推荐权重`使用`role=quiet`。
- 保存后分析页只读摘要立即更新。

设置页不包含模型判断、判断记录或保存判断。

## 键盘与可访问性

- 正文对比度≥4.5:1，大字≥3:1；焦点环与相邻背景≥3:1。
- 橙色主按钮必须选择能让文字达到4.5:1的深橙状态，浅橙只用于背景和当前位置底色。
- 导航当前位置同时使用竖线、图标、文字和浅背景。
- 图表同时显示名称、排名和数值，绿色不是唯一信息载体。
- 错误、风险、成功和当前数据都使用图标加文字。
- 所有输入框都有可见label，placeholder只提供示例。
- Tab顺序：侧栏切换、分析、导入记录、设置、文件状态、导入新数据、辅助搜索、查询、排序、本次推荐要求、生成AI推荐、图表、加载更多、加载全部、表格。
- Esc关闭弹窗；Enter触发当前默认按钮；AI费用确认默认焦点落在取消。
- 长中文说明自然换行，按钮、KPI数字和表头不换行；不出现单字孤行。

## 响应与窗口验收

### 1280×820

- 展开侧栏184px或收起侧栏64px。
- 分析态同时完整显示文件栏、操作区、5张KPI、10条图、表格表头和至少10行数据。
- 空数据态左右两列完整显示，来源说明不被裁切。
- 页面无纵向主滚动条和无意义横向滚动条。

### 1080×700

- 展开和收起两种侧栏状态都必须可用，不强制自动收起。
- 分析态同时完整显示5张KPI、10条图、表格表头和至少7行数据。
- 操作区所有按钮文字完整，不允许费用提示被省略。
- 空数据态优先保持两列；系统缩放导致不足时只折叠来源说明内容，不折叠导入主区。
- 页面无纵向主滚动条；设置页内容允许自身纵向滚动。

### 系统缩放

- 在Windows125%和150%缩放下复核1080×700最小窗口。
- 图标、文字和焦点环不能模糊。
- 若缩放后无法满足7行表格，优先压缩卡片间距和Top10图表高度，不把表格行高降到26px以下，也不隐藏费用提示。

## 反AI套路自检

1. 字体沿用项目中文桌面字体，未额外引入常见网页字体。此处与frontend-design的非系统字体建议冲突，项目现状和参考图优先。
2. 配色仅保留橙色操作、绿色数据和必要语义色，没有紫色渐变或平均分配多色。
3. 页面结构来自用户提供的桌面参考图和词元分析任务，没有Hero数字大屏、玻璃拟态、三等分宣传卡或装饰性渐变。
4. Top10图、完整搜索词表、当前推荐范围和六项权重形成词元分析器特有内容，不靠通用看板装饰辨识产品。

## 待决策项

1. 导入记录页需要后端新增本地导入事件记录。现有metadata只有当前批次时，页面只能展示当前一条记录和后续事件，不能伪造历史。
2. 参考图空状态写有导入前可备份，但当前产品规范只明确新数据替换旧数据和失败保留旧数据。本方案不增加备份按钮；若需要备份，应单独确认文件位置、恢复规则和失败处理。
3. 项目现有主题使用蓝色主操作，本次用户明确要求参考图的橙色主操作和绿色数据强调。新正式UI应统一替换页面主操作语义，避免蓝、橙两套主色并存。

## 给code-writer的交付说明

- 新正式UI外壳固定为左侧导航加右侧文件栏和内容区，不再实现全宽顶部工具条页面。
- 需要新增展开与收起侧栏、空数据页、Top10单系列水平条形图、导入记录页和设置页容器。
- 分析页保留辅助搜索、本次推荐要求、生成AI推荐、排序、加载更多、加载全部、KPI和7列表格。
- 推荐模式与六项权重在分析页只读展示，编辑入口只在设置页。
- 完整移除模型判断相关UI、文案、状态和保存入口；不要把AI推荐改名为模型判断。
- 颜色统一通过`surface-base`、`surface-card`、`accent-primary`、`accent-primary-soft`、`data-accent`、`data-accent-soft`、`border-subtle`和语义状态角色集中定义，不在组件代码里硬编码颜色。
- 字号继续沿用现有语义选择器；新增`pageTitle`、`chartValue`和`kpiCompact`时按现有字号阶梯补充。
- Top10和表格必须使用同一排序状态、同一当前范围和同一次查询结果，切换排序不得触发AI。
- 导入、AI推荐和模型连接测试遵守项目并发与关闭限制。
- 实施验收截图至少8张：1280展开数据态、1280收起数据态、1080展开数据态、1080收起数据态、1280空数据态、1080空数据态、设置页、AI请求确认弹窗。
