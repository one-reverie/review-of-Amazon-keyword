# 词元分析器桌面端增强方案

日期：2026-08-09

适用范围：分析页、导入流程、AI推荐结果窗口。本文只覆盖桌面端PySide6界面，不改变词元统计、AI评分和现有6项业务筛选的数据口径。

## 目标与边界

本轮让用户在同一个分析工作区完成表格排序、Excel式列筛选、固定搜索、下钻、导出、列宽调整和最近操作恢复；同时补充成本类指标和兼容更多导入文件类型。

不在本轮增加低频匹配搜索词Top10图。若当前分支仍有该图、开关、空态或说明，一并移除，不留下占位区域。

### DesignThinking

| 项目 | 决策 |
|---|---|
| Purpose | 让运营人员在广告搜索词数据中快速限定范围、比较指标、下钻到完整搜索词，再带着相同条件导出或发起AI推荐。 |
| Tone | 克制、实用的Windows业务分析工具。信息密度高，但每个操作都有明确位置和即时反馈。 |
| Constraints | PySide6桌面应用；现有左侧导航、顶部文件区、6项关联筛选、Top10、表格和AI推荐需保持；窗口最小1080×700；单批次数据可达数十万行；导出和导入不能阻塞界面。 |
| Differentiation | 搜索词、关联广告活动、完整搜索词明细和当前筛选范围在同一视图连续呈现，用户不需在多个窗口之间核对口径。 |

### frontend-design取舍

| 维度 | 决策 | 原因 |
|---|---|---|
| Typography | 保留`Microsoft YaHei UI`，数字继续使用`Segoe UI`。 | 项目已验证Windows中文显示和数字比较效果，局部换字体会破坏字宽与安装环境一致性。 |
| Color&Theme | 橙色继续代表本地操作、选中和焦点；绿色继续代表数据图形与AI推荐；中性色负责背景、边界和禁用。 | 现有橙绿职责已稳定，新增排序和筛选不另起色相。 |
| Motion | 只用于下拉弹层、局部数据刷新、导出任务状态和图表值更新。 | 高频分析操作需要反馈，不适合整页入场或卡片位移动画。 |
| SpatialComposition | 主分析页保持纵向阅读，搜索条固定在表格上缘，筛选、图表和表格各有稳定边界。 | 固定操作点和连续数据区比不对称装饰更适合重复查询。 |
| Backgrounds&VisualDetails | 继续用近白根背景、白色卡片、细分隔、浅橙选中和浅绿数据强调；下拉弹层保持不透明。 | 文字、数值和长广告活动名需要稳定对比度，不能让背景图形干扰阅读。 |

项目现状与frontend-design关于非系统字体、破格布局的建议冲突。本方案按项目现状执行；如需更换字体或建立新设计系统，应单独立项。

## 项目设计语言映射表

以下为扫描到的事实，也是本方案的唯一取值来源。项目没有独立token文件，颜色和尺寸集中写在`src/token_analyzer/theme.py`的QSS选择器中；实施时复用现有选择器或按同一命名风格新增选择器，不把新的裸颜色写入组件。

| 类别 | 已有事实 | 本轮使用方式 |
|---|---|---|
| 样式系统 | 单文件QtQSS，使用类型选择器、`objectName`和`role`、`accent`动态属性。 | 新增控件继续使用`objectName`和动态属性，不引入UI库、CSSModules或第二套主题。 |
| 背景与卡片 | `appRoot`、`page`、`dashboardContent`使用暖灰近白背景；`controlCard`、`chartCard`、`tableCard`使用白色卡片、细边框、8px圆角。 | 搜索工具条、导出弹层和活动关联区复用同族表面、边框和圆角。 |
| 操作语义 | `role=primary`是橙色主操作，`role=quiet`是描边次操作，`role=ai`是绿色AI操作。 | 搜索、导出确认、导入继续使用既有按钮角色；AI推荐导出使用次操作，避免与生成AI推荐竞争。 |
| 文本层级 | `brandTitle`和`pageTitle`为24px，`sectionTitle`为15px，正文为13px，`filterLabel`和辅助提示为12px。 | 搜索标签和筛选摘要用12px，表格工具条标题用15px，数据与菜单正文用13px。 |
| 数字 | KPI值使用`Segoe UI`，表格数值右对齐。 | 成本、销售额、CPC、ACOS、导出预览和筛选计数继续用等宽数字与右对齐。 |
| 间距与圆角 | 控件常用36px高、5px圆角；搜索框42px；卡片8px圆角；页面与卡片内边距常用12px、16px。 | 固定搜索条42px输入高度，图标按钮36px，表头32px，数据行28px。 |
| 边框与阴影 | 卡片无常规阴影；输入和表格有可见focus边界；浮层使用系统阴影。 | 表头菜单、导出菜单、关联广告活动菜单使用不透明卡片与浮层阴影，不给主表增加阴影。 |
| 动效 | 已有方案使用`motion-fast`，160ms`ease-out`；侧栏使用`motion-panel`，180ms`ease-in-out`。 | 下拉、排序刷新、局部加载使用`motion-fast`；退出使用120ms`ease-in`；系统减少动态效果时直接切换。 |
| 类名风格 | `searchInput`、`filterCombo`、`tableCard`等为语义化`objectName`。 | 可新增`tableToolbar`、`headerFilter`、`exportMenu`、`activityContext`、`historyAction`等名称，不重命名既有选择器。 |

## 信息层级

| 层级 | 元素 | 视觉权重 |
|---|---|---|
| 第一层级 | 当前表格标题、固定搜索、表头排序状态、当前数据范围、完整搜索词结果。 | `sectionTitle`、表头加粗、排序箭头与可见筛选摘要共同表达，不只依赖颜色。 |
| 第二层级 | 6项业务筛选、KPI、Top10、导出、关联广告活动、AI推荐范围。 | 正文和辅助文字层级，卡片白底或浅强调底色。 |
| 第三层级 | 已显示项数、撤销恢复、筛选计数、源列缺失说明、状态文字、tooltip。 | `mutedLabel`和图标加文字，不抢占数据阅读。 |

### 尺寸与断点

- 1280×820展开侧栏时，主区外边距继续使用现有12px至16px。筛选和KPI可纵向延展，表格卡获得剩余空间。
- 1080×700时，6项业务筛选使用既有两行规则。表格内允许有意义的横向滚动，固定工具条不能被横向内容带走。
- 表格卡工具条固定在表格上边缘，表头随表格内容纵向滚动保持固定。页面纵向滚动时，表格工具条在顶部文件区下方吸附；离开表格卡后恢复页面流动，不覆盖Top10或筛选栏。
- 固定工具条不新增第二个搜索入口。现有分析操作区的搜索、搜索按钮和清空按钮迁移到该位置，保留原有快捷键与搜索口径。

## 组件规格清单

### 固定搜索、撤销恢复与导出工具条

| 组件 | 类型 | 规格与内容约束 | Default、Hover、Active、Disabled |
|---|---|---|---|
| `tableToolbar` | 页面专属容器 | 左侧显示`词元排行`或`搜索结果：〈词元〉`，副文本显示当前范围与总项数。中部为可见label`辅助搜索`、弹性搜索框、`搜索`和`清除`。右侧依次为撤销图标、恢复图标、`导出⌄`。搜索框固定在表格上方，长查询词单行省略并在hover时显示全文。 | 默认白底和底部分隔；hover不改变容器；任务运行时搜索和导出按任务状态禁用，标题与范围仍可读。 |
| `historyAction` | 新增公共图标按钮 | 使用当前图标体系的弯箭头，视觉尺寸20px，点击热区36×36px。仅图标不加常驻文字，但必须有tooltip和可访问名称`撤销Ctrl+Z`、`恢复Ctrl+Y`。 | 默认中性图标；hover用浅橙背景；pressed用现有按下表面；无历史时禁用并显示原因tooltip。 |
| `searchInput` | 复用既有组件 | 保持42px高、现有focus规则和Enter搜索。placeholder为`输入词元或连续词组`。搜索结果下钻后输入框显示词元，左侧另有可删除的词元上下文标签，不把标签文字拼入输入内容。 | 默认可编辑；hover边框增强；focus使用现有2px焦点边界；数据任务执行中禁用且保留原输入。 |
| `exportMenu` | 新增页面专属菜单 | `导出⌄`打开不透明弹层，先选范围，再选格式，最后确认。范围：`当前已显示N项`、`当前筛选全部N项`。格式：`Excel工作簿.XLSX`默认选中、`CSV文件.CSV`可选。确认按钮显示`导出N项`。文件名默认包含当前页面名称、范围和导出日期。 | 按钮默认使用`role=quiet`；hover显示浅表面；open保持浅橙状态和向上箭头；没有可导出数据时disabled并说明。 |
| `exportProgress` | 新增局部状态 | 导出开始后工具条右侧显示进度、对象与取消入口，例如`正在导出当前筛选全部48,690项`。完成显示图标加文件名，失败显示错误图标、原因和`重试`。 | 进度中导出按钮disabled；其他浏览操作保持可用；失败不清空当前表格。 |

#### 最近操作规则

- 历史栈最多保存5步，最新操作在最上层。
- 可撤销的状态：排序维度、表头筛选、6项业务筛选、辅助搜索与清除、词元下钻与返回排行、关联广告活动选择、表格列宽。连续拖动列宽在鼠标释放时只记为1步。
- 不进入历史栈的动作：导入新文件、加载更多、加载全部、导出、AI推荐请求、模型配置与权重修改。导入替换单批次数据不提供恢复旧数据，以免给出不可实现的恢复承诺。
- 执行新操作后清空恢复栈。撤销或恢复后，恢复对应的范围、搜索、活动关联、排序、表头筛选和列宽，并保持表格滚动位置；状态栏用文字说明结果。
- 快捷键：`Ctrl+Z`撤销，`Ctrl+Y`恢复，`Ctrl+Shift+Z`也可恢复。焦点在可编辑文本框内时，优先执行文本本身的撤销恢复，不触发表格历史。

### 表头点击排序与Excel式筛选

| 项目 | 规格 |
|---|---|
| 可排序列 | 词元或完整搜索词列只负责下钻与文本筛选。其余指标列均可排序：匹配记录数、曝光量、点击量、订单数、点击率、转化率、成本、销售额、ACOS、CPC。 |
| 点击分区 | 表头文本区点击排序；右侧20px筛选箭头点击打开筛选菜单。两者点击热区不重叠，避免误操作。 |
| 排序联动 | 首次点指标列使用降序，再点同列切换升序，第三次回到该列默认降序。排序后同步更新表格、Top10标题与条形、状态栏和表头箭头。排序不改搜索、6项筛选或列筛选。 |
| 表头表达 | 当前列显示排序箭头、排序方向文字tooltip和焦点边界。非当前列保持中性。数字列头与数字右对齐，文本列左对齐。 |
| 文本列菜单 | 顶部有本列搜索框，其下为全选、清除、可勾选值列表与每项匹配数。长词元和广告文本单行省略，hover显示全文。 |
| 数值列菜单 | 顶部显示`全部数值`，提供等于、大于、小于、介于的条件输入；百分比输入按用户可见百分比解析。数值不列出全量离散值，以免数十万条数据造成菜单不可用。 |
| 关联规则 | 每个表头菜单候选按其他已生效条件计算：6项业务筛选、辅助搜索、下钻上下文、关联广告活动和其余表头筛选都参与，本列自身暂时排除。每个可选值至少可返回1条记录。 |
| 菜单底部 | 显示`已根据其他条件显示A/B项`和`清除本列筛选`。有列筛选时，表头箭头旁出现现有橙色语义的筛选状态标记，并有文字tooltip说明条件。 |
| 多条件 | 不同列筛选取交集，同一文本列已勾选值取并集，数值条件在同一列仅允许1个区间或比较式。筛选摘要以可删除标签显示在固定工具条标题下方，提供`清除全部列筛选`。 |

表头菜单最大宽440px、最大高320px，选项行36px，内容背景不透明。超过20个文本候选时显示菜单内搜索框。菜单打开与关闭使用160ms`ease-out`和120ms`ease-in`，减少动态效果时立即切换。

### 表格列、列宽与横向滚动

| 项目 | 规格 |
|---|---|
| 列结构 | 排行页：词元、匹配记录数、曝光量、点击量、订单数、点击率、转化率、成本、销售额、ACOS、CPC。下钻结果页仅把第一列改为完整搜索词。 |
| 初始宽度 | 词元或完整搜索词158px；匹配记录数80px；曝光量88px；点击量80px；订单数72px；点击率76px；转化率76px；成本90px；销售额96px；ACOS80px；CPC88px。首次加载可按视口补足首列余宽。 |
| 调整方式 | 11列都使用相同的表头分隔线拖动规则。取消第一列最大宽、总宽度和其他列互相补偿限制。用户可把任意列向任意方向拖动至项目现有最小列宽。 |
| 自动适配 | 双击任意分隔线只自动适配该列内容。自动适配后的宽度同样进入列宽历史。新批次首次显示使用初始宽度，已调整宽度只在当前批次与当前窗口会话保留。 |
| 横向滚动 | 当列总宽超过表格视口时显示水平滚动条，属于有意义的滚动。固定工具条不随表格横向移动。若所有列总宽未超过视口，不显示水平滚动条。 |
| 内容对齐 | 第一列左对齐；其余列及表头右对齐。数值使用等宽数字，整数保留千分位，成本、销售额和CPC按当前币种的小数规则显示，ACOS、CTR、CVR显示两位百分比。 |
| 文本截断 | 词元和完整搜索词单行末尾省略，tooltip展示全文。数值不省略；无法计算时显示项目既有空值符号，并在相关表头说明缺失原因。 |

### 词元双击下钻与关联广告活动

| 项目 | 规格 |
|---|---|
| 触发 | 在排行页双击词元列，或选中词元后按Enter。搜索结果页双击不再次下钻。 |
| 结果范围 | 保留当前6项业务筛选、全部表头筛选、当前排序和列宽；将第一列切换为完整搜索词，并加入词元上下文。表格标题改为`搜索结果：〈词元〉`，副文本显示匹配完整搜索词数和关联广告活动数。 |
| 词元关联 | 关联计算忽略大小写、连续空格差异；英文按单词边界匹配，连续词组按相邻顺序匹配；中日韩无空格文本和ASIN仍按完整字符串匹配，不按单字拆分。 |
| 活动呈现 | 固定工具条第二行显示`关联广告活动N个`的可展开控件。打开后列出当前范围内涉及该词元的广告活动名、对应完整搜索词数和匹配记录数，支持勾选一个或多个活动继续收窄结果。长名称省略并提供全文tooltip。 |
| 活动关系 | 关联广告活动是下钻结果的局部筛选，不静默改写顶部6项业务筛选中的广告活动。工具条摘要明确显示`关联活动`，用户可单独清除；返回排行时一起清除。 |
| 返回 | 清除词元上下文或点击`返回词元排行`后恢复排行页与进入下钻前的同一数据范围。此操作纳入最多5步历史。 |

### 图表与左侧文字区域

保留当前排序维度Top10。删除低频匹配搜索词Top10及其标题、提示、占位空态和相关开关。

Top10图左侧标签区增加可拖动分隔线，默认宽度为图表可用宽度的22%。用户可在132px至360px之间左右调整，双击分隔线回到默认宽度。拖动中显示竖向调整光标与当前位置预览，不遮挡条形hover区域；鼠标释放时记入历史。窗口变窄时先降到132px，再缩短词元文本，数值区不被覆盖。

### 成本、销售额、ACOS、CPC

| 指标 | 表格、排序与图表规则 | 源数据缺失时的表头问号说明 |
|---|---|---|
| 成本 | 使用源表成本列，参与表头排序、数值筛选、Top10、下钻和导出。 | `源文件未提供成本列，此指标不可用。` |
| 销售额 | 使用源表销售额列，参与表头排序、数值筛选、Top10、下钻和导出。 | `源文件未提供销售额列，此指标不可用。` |
| ACOS | `成本÷销售额`。销售额为0或任一源值缺失时为空。参与排序、数值筛选、Top10和导出。 | `ACOS需要成本和销售额。当前文件缺少所需源列。` |
| CPC | `成本÷点击量`。点击量为0或成本缺失时为空。参与排序、数值筛选、Top10和导出。 | `CPC需要成本和点击量。当前文件缺少成本列或当前记录点击量为0。` |

- 成本和销售额按源文件币种显示，不进行跨币种换算。当前范围包含多币种时，表格逐行展示原始数值；KPI或导出汇总页不显示跨币种合计。
- 源表没有成本或销售额列时，4个新增表头仍固定显示，以保证列结构稳定。不可用的表头带问号图标和tooltip，单元格显示空值；排序箭头、数值筛选入口和Top10排序选项禁用，并给出相同原因。
- 成本、销售额、ACOS、CPC不额外增加第二排KPI，以免压缩主表和固定搜索条。它们作为可排序、可筛选、可导出的明细指标出现在表格和Top10中。

### 导入与导出

| 场景 | 规格 |
|---|---|
| 导入文件选择 | 文件选择器可见类型包括`.xlsx`、`.xlsm`、`.csv`、`.txt`。原`.xlsx`流程不变。 |
| CSV与TXT预检 | 选择后在导入确认区域展示文件类型、识别到的编码与分隔方式、首行字段预览和必需列检查结果。TXT按检测到的制表符、逗号或分号分隔读取；无法判断时显示可选分隔符控件。 |
| XLSM | 按首个工作表读取数据，不运行宏，不保留宏，不把工作簿宏写入导出文件。 |
| 可选指标列 | 预检同时标注成本和销售额是否已识别。缺失不阻止导入，只在确认信息和后续表头说明中如实显示。 |
| 常规导出 | 导出菜单的`当前已显示`严格对应表格当前渲染行，`当前筛选全部`对应所有已生效的6项筛选、表头筛选、辅助搜索、下钻和关联广告活动条件，但不受加载更多限制。导出列顺序跟随当前表格列顺序。 |
| XLSX导出 | 默认格式。首行保留表头，第二工作表或元数据区写入导出范围、搜索词元、筛选摘要、排序字段和导出时间，避免数据文件脱离口径。 |
| CSV导出 | 使用UTF-8BOM，保证Excel直接打开中文字段不乱码。CSV只包含数据表，不增加第二工作表；同一口径信息写入文件名和导出完成提示。 |
| AI推荐导出 | AI结果窗口工具条新增`导出推荐词`次按钮，只导出`Excel工作簿.XLSX`。数据表按结果窗口可见的推荐列导出，另附推荐模式、六项权重、原始范围、关联筛选、生成时间和风险说明。没有AI结果时按钮disabled。 |

### 交互与动效规范

| 场景 | 反馈与过渡 |
|---|---|
| 表头排序 | 先更新表头箭头与标题，再刷新表格和Top10条形，160ms`ease-out`。处理中只禁用重复排序点击，不禁用表格滚动。 |
| 表头筛选 | 菜单内选择后一次性刷新候选、摘要、KPI、Top10和表格。超过200ms时，在当前表头箭头区显示进度环；完成后焦点回到原表头。 |
| 搜索与下钻 | 搜索执行时，固定工具条显示`正在查找完整搜索词`，保留上次成功结果直到新结果就绪。下钻完成后焦点移到表格标题并播报范围。 |
| 导出 | 导出在后台进行，工具条局部显示进度。完成和错误均用图标加文字，不只使用颜色。 |
| 图表标签拖动 | 拖动时仅更新标签区宽度，不播放条形重排。释放后120ms`ease-in`结束预览。 |
| 弹层 | 表头、导出和活动关联菜单进入160ms`ease-out`，退出120ms`ease-in`。Windows减少动态效果开启时直接出现或关闭。 |

## 键盘、可访问性与状态

- 所有正文对比度不低于4.5:1，焦点环与相邻背景对比度不低于3:1。排序、筛选、错误、当前范围和不可用指标都使用图标或文字辅助，颜色不作为唯一信息载体。
- 表头文字区可用Enter或Space排序，筛选箭头可用Alt+下方向键或Space打开菜单。菜单支持上下方向键、Home、End、Enter与Esc。
- 图标按钮、导出按钮、表头筛选箭头和关联活动控件必须暴露完整可访问名称。桌面环境下点击热区保持至少36×36px；若后续复用到触控设备，热区提升到44×44px。
- 搜索、导出和导入均有可见label或明确按钮文字，placeholder不承担唯一说明。错误信息在触发控件附近显示，并配错误图标。
- 活动名、词元和文件名长文本使用单行省略与全文tooltip。中文说明自然换行，表头、按钮和数值不换行，避免单字孤行。

## 反AI套路与项目一致性自检

1. 字体继续使用项目已落地的Windows中文与数字字体，未混入网页常见字体。
2. 不增加紫色渐变、玻璃拟态、无语义多色或纯白大背景。橙、绿和必要语义状态保持既有职责。
3. 排版以数据工具实际动作组织，固定搜索、列筛选、下钻和导出都有对应上下文，不使用宣传页式卡片组。
4. 去掉颜色后，标题、排序箭头、筛选摘要、数量、边界与位置仍能区分信息层级。
5. 缩小到60%时，固定搜索和表头仍可见，图标按钮有tooltip，表格不因新增指标而遮住数值。
6. 同类按钮、下拉菜单、图标按钮、tooltip与焦点样式均复用现有语言。色相不超过橙、绿和必要语义色。

## 待决策项

1. 成本与销售额的源列名称映射尚未在项目规范中定义。导入预检需要确认可接受的字段别名，避免不同报表标题无法识别。
2. `当前已显示`导出是否需要包含用户在表格中手动隐藏或调整过的列。本文默认按当前列顺序导出全部11列，不把列宽和省略文本写入文件。
3. 关联广告活动当前按精确连续词元规则计算。若业务需要更宽松的包含匹配，应明确英文部分匹配、词干变化和拼写变体的口径，否则可能引入不相关活动。
4. AI推荐导出默认只提供XLSX。若需要CSV，应补充推荐理由与风险说明在CSV中的列结构与换行规则。
