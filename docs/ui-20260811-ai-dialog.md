# AI推荐弹窗设计规格

## 目标

弹窗用于核对和导出模型推荐结果，不承担数据编辑。界面保持企业工具的克制和高信息密度，优先保证指标、推荐理由和风险提示可完整查看。

## 窗口与布局

- 打开时默认最大化，保留系统最大化、还原和关闭能力。
- 顶部依次展示推荐范围、记录数、模式、模型和只读说明；中部为单词词元、组合词元两个页签；底部保留导出与关闭。
- 表格超出可视宽度时使用水平滚动，不压缩或拉伸末尾列。

## 表格

- 视觉序号列由垂直表头提供，词元为第一个数据列；二者在水平滚动时固定。
- 冻结词元视图与主表共享同一数据模型和选中模型，只显示词元列，避免复制数据或出现重复文字。
- 冻结视图和主表同步垂直滚动位置、行高及选中行。
- 所有列先按内容计算初始宽度，再切换为可拖动模式。推荐理由初始宽度不小于360，风险提示不小于320；不使用Stretch。
- 所有单元格禁用编辑触发器并移除可编辑标记。双击、输入和粘贴均不能改变内容。
- 每个单元格悬停显示完整值。当前单元格支持`Ctrl+C`；词元列右键显示复制完整内容。

## 交互边界

- 冻结视图不建立独立数据副本，不提供编辑器，也不增加第二套选择状态。
- 拖动词元列宽时，同步更新冻结区和主表；拖动其他列只改变对应主表列。
- 导出仍读取原推荐结果对象，不依赖表格显示宽度、滚动位置或当前选择。
