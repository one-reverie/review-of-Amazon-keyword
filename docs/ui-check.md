# 正式UI筛选与纵向页面核查记录

日期：2026-08-03

## 已核查

- 界面结构已按用户参考图调整为左侧导航、顶部文件区、搜索区、KPI、Top10图和底部表格。
- 左侧分析、导入记录、设置可以展开和收起；收起后保留图标和提示。
- 模型接口、推荐模式和权重入口位于设置页；主分析页保留本次推荐要求和生成AI推荐。
- 模型判断按钮、结果卡、置信度、判断原因和保存判断均未出现在程序界面。
- Top10图表使用当前排序维度，切换排序后与表格同步刷新；搜索后改用全部匹配范围的排序结果。
- 1280×820窗口完整显示10条Top10图和至少7行表格；1080×700窗口完整显示Top10并保留可滚动的表格数据行。
- 表格7列铺满可用宽度，全部列可拖动，数值列右对齐。
- 首页默认按点击量排序，搜索结果仍保留全部指标并与排序维度联动。
- 日期、币种、广告组合、广告活动、广告组和搜索词类型筛选均已恢复；筛选与搜索取交集，并同步更新KPI、Top10、表格和AI推荐范围。
- 6个筛选框均显示固定下拉箭头；弹层加宽，当前值和下拉选项均保存完整文字悬停提示。
- 筛选选项根据其余已选条件关联收窄，每个可选值都至少对应1条记录；重置后恢复完整选项。
- 选项收窄时显示受影响字段数，悬停列出各字段当前项数与全部项数；没有收窄或重置后隐藏。
- 1280宽度下6项筛选单行显示；1080宽度下自动改为两行，搜索、清空、重置筛选和第5张指标卡均未被裁切。
- 分析页使用纵向滚动，不再强制压缩到一屏；Top10完整显示10项，表格在下方保留独立滚动。
- Top10整行可触发悬停浮层，内容包含完整词元、名次、当前排序指标、匹配记录、曝光、点击、订单、点击率和转化率。
- AI按钮旁显示当前范围和可能产生的模型费用；联网前再次确认服务商、模型、范围、模式和本次要求。
- 导入新Excel前确认会替换当前数据。
- 无数据时展示导入引导，不显示误导性的旧指标。
- 导入和AI推荐互斥，后台任务运行时阻止直接关闭窗口。
- API Key使用Windows当前用户加密保存；携带密钥的远程地址只允许HTTPS，本机地址可使用HTTP。
- 包含Windows当前用户加密在内的34项自动测试全部通过。筛选关联、稀疏字段占位、搜索联动、AI范围、英文介词排除、连续组合边界、纵向滚动、1080响应式布局和图表悬停均已有自动测试。

- 尚未制作安装包，需等用户确认第一版正式UI后进入包装阶段。
- 推荐结果导出、推荐历史和长任务取消属于新增功能，不纳入本轮视觉改版。
